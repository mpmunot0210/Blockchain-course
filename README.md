# Blockchain Technologies: Business Innovation & Application

An MIT Sloan–caliber interactive course platform covering blockchain fundamentals, DeFi, stablecoins, tokenisation, enterprise applications, AI convergence, and programmable payments.

## Course structure

| Week | Focus | Hours |
|------|-------|-------|
| **Week 1** | Foundations & economic logic (M1–M3) | 12–14 hrs |
| **Week 2** | Financial applications & institutional landscape (M4–M6) | 13–15 hrs |
| **Week 3** | Enterprise strategy, frontiers & capstone (M7–M9) | 13–15 hrs |
| **Bonus** | Programmable payments & blockchain rails (M10a–M10c) | 4–5 hrs |

**Total: ~44 hours · 10 modules · 7 assessments · 1 final capstone project**

## Features

- Full syllabus with lecture content, case studies, readings, and frameworks
- Interactive 15-question quiz with instant grading and explanations (Module 1)
- Progress tracking saved to localStorage
- Responsive design with light/dark mode support
- Written assessment briefs for capstone projects

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Deployment

### Vercel
```bash
npm i -g vercel
vercel
```

### Netlify
```bash
npm run build
# Upload the `dist` folder to Netlify
```

### GitHub Pages
```bash
npm run build
# Deploy the `dist` folder
```

## Tech stack

- React 18

- IBM Plex Sans typography

- Zero external UI dependencies
